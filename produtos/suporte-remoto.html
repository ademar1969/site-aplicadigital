Suporte Remoto

Atenda e seja atendido à distância. Veja e controle a tela de outro computador, envie arquivos e resolva problemas sem sair do lugar, de graça.

Baixar para Windows Baixar app Android

Windows 10/11 · Android 6.0 ou mais novo

Recursos

Simples para quem pede ajuda

  • ID fixo para cada computador: é só passar o número para quem vai atender
  • Você aceita cada acesso, ou define uma senha para acesso sem ninguém na frente do computador
  • Envio de arquivos entre os computadores
  • Fica em segundo plano (ícone perto do relógio) e inicia com o Windows
  • Atualiza sozinho, sem interromper um atendimento em andamento
  • Lista de recentes com indicação de quem está online, nome do computador e apelido
  • App Android para controlar o computador pelo celular
Como usar

Pronto em 3 passos

Baixe e instale. Não precisa de Java nem de administrador. Se o Windows avisar, clique em "Mais informações" → "Executar assim mesmo".

Abra o Suporte Remoto e veja o seu ID na tela.

Passe o ID para quem vai te atender e aceite a conexão quando aparecer o pedido.

Gestos no celular: um dedo move o cursor, toque é clique, toque longo é clique direito e dois dedos rolam a página.

Precisa de atendimento agora?

Instale o Suporte Remoto e chame a gente: em poucos minutos estamos na sua tela.
