# Site da Aplica Digital — aplicadigital.app.br

Site estático (HTML + CSS + JS, sem compilação) publicado pelo **GitHub Pages**.

- `index.html` — página inicial (produtos, downloads, dúvidas e contato)
- `produtos/*.html` — uma página por produto
- `assets/estilo.css` — visual do site
- `assets/site.js` — topo, rodapé e **contatos** (WhatsApp, e-mail, Instagram: edite o bloco `CONTATO` no começo)
  e botões de download que buscam sozinhos a versão mais nova publicada no GitHub
- `CNAME` — domínio próprio (aplicadigital.app.br)

Para mudar um texto: edite o HTML e faça commit; o GitHub Pages publica em cerca de 1 minuto.
