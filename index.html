Dúvidas frequentes

Perguntas que sempre aparecem

O VendasNFe emite NF-e e NFC-e de verdade?

Sim. O sistema transmite direto para os webservices da SEFAZ (NF-e 4.00 e NFC-e), com certificado digital A1. Também consulta e cancela notas na SEFAZ e envia o DANFE por e-mail.

Preciso instalar o Java ou o banco de dados separado?

Não. O instalador do VendasNFe já instala o Java e o MariaDB, cria o banco e os atalhos. O Suporte Remoto também já vem com o Java.

Funciona com mais de um computador (caixas)?

Sim. Um computador fica como servidor do banco de dados e os outros caixas apontam para ele. O banco também pode ficar em um servidor na nuvem.

Como recebo as atualizações?

Automaticamente. Ao entrar, o sistema procura versão nova, mostra o que mudou e atualiza com um clique. Você pode deixar para depois.

O Suporte Remoto é gratuito?

Sim. Basta instalar, passar o número do ID que aparece na tela e quem vai te atender se conecta com a sua permissão.

Vocês oferecem treinamento?

Sim. Pelo próprio VendasNFe dá para agendar um treinamento com a equipe, além do assistente de ajuda que explica cada tela.
